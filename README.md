## Overview

Psychedelicraft Plus is a comprehensive Minecraft mod that adds realistic drug mechanics, effects, and crafting systems to the game. This enhanced version builds upon the original Psychedelicraft by Ivorius, with new features, balanced mechanics, and expanded content while maintaining the core experience that made the original mod popular.

### Key Features

- **Realistic Drug Effects**: Utilizes shaders and advanced rendering to create authentic visual and audio effects
- **Complex Crafting Systems**: Multi-step crafting processes for synthetic drugs requiring various machines and equipment
- **Growing & Processing**: Cultivate plants, dry materials, extract compounds, and refine products
- **Tutorial System**: Built-in `/tutorial` command with smart inventory checking for step-by-step guidance
- **Comprehensive Item Set**: Hundreds of items including plants, chemicals, equipment, and finished products

## Usage

### Getting Started

1. **Obtain Seeds**: Find seeds in creative tab or explore world
2. **Build Equipment**: Craft drying table, mash tub, flask
3. **Grow Plants**: Plant seeds and wait for maturity
4. **Harvest & Process**: Dry plants, extract compounds, craft final products
5. **Use Tutorial**: Type `/tutorial {drug}` for step-by-step guidance

### Commands

- `/tutorial {drug}`: Get crafting instructions for specific drug
- `/tutorial`: List available tutorials
- `/drug`: Admin command for drug management (requires OP level 2)

### Creative Tabs

- **Psychedelicraft Plus General**: All items, equipment, and materials
- **Drinks**: Fluid containers and filled beverages
- **Weapons**: Molotov cocktails (if enabled in config)

## Configuration

Access mod settings in:
- `config/psychedelicraft-common.toml`

### Key Settings

- **enableHarmonium**: Enable rift jars and harmonium
- **enableRiftJars**: Allow rift jar spawning
- **disableMolotovs**: Disable molotov cocktails
- **shader settings**: Configure visual effects intensity
